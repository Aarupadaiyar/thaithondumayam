# 3D models

Drop files here with these exact names. The site uses them automatically;
until then it shows the built-in procedural versions.

| File          | What                                  | Target height |
|---------------|---------------------------------------|---------------|
| shiva.glb     | Hero centrepiece (Shiva / lingam)     | auto-scaled   |
| trident.glb   | Trishula that flies through the scroll | auto-scaled   |
| fire.glb      | Optional flame, placed at the base     | auto-scaled   |

Format: glTF binary (.glb), Y-up, Draco compression OK, textures embedded,
ideally under 8 MB each. Embedded animations in fire.glb play on loop.
